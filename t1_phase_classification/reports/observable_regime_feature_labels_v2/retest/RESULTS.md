# TLE 特征标签 v2 聚类复测结果

## 评测口径

本次复测保持 TLE 输入、NORAD 级 70/15/15 划分、无监督模型和三种子不变，
仅将评测标签替换为互斥的数据特征状态标签。簇到状态的 Hungarian 映射只使用训练集。
测试结果属于标签重组后的回顾性评测，不是新的未见冻结测试。

主指标只包含 `STABLE_ORBIT`、`SUSTAINED_RAISE`、`SUSTAINED_DECAY`。
测试主样本为 10,209 个窗口、376 个含主状态的目标、8 个主状态边界。

## 关键发现

1. **Raw PCA + KMeans 仍是最强方法。** 测试 ARI=0.7938、NMI=0.6668、Macro-F1=0.7010。稳定和持续升高 F1 分别为 0.9781、0.8884。

2. **持续降低仍是主要薄弱点。** Raw 方法对该类 recall=0.8416，但 precision=0.1375，F1 只有 0.2364；说明许多稳定窗口被误报为降低。

3. **PELT 更平滑，但分类能力较弱。** 对称 segment IoU=0.8905，比 Raw 高 +0.90%，但 Macro-F1 低 32.84%，并且持续降低 F1=0.0000。高 segment IoU 主要受稳定长段占比驱动。

4. **Transformer 自监督预测表征没有形成可用状态簇。** ARI=-0.0168、NMI=0.0026，Macro-F1=0.3244，只比恒定稳定控制的 0.3148 略高；三个种子平均产生 1522 个边界，而真值只有 8 个。

5. **标签重组没有改变方法排序。** 相对 v1，Raw Macro-F1 仅变化 +0.0013，PELT 变化 +0.0001，Transformer 变化 +0.0001。

## 建议的下一步实验

1. 为 Transformer 增加变化点、局部斜率或片段一致性目标，而不是继续只优化下一 TLE 预测。
2. 对持续降低类使用按目标重采样或代价敏感的簇解释，重点压低误报并扩充独立降低目标。
3. 单独调节 PELT penalty/min-size，并以 Macro-F1 与边界误报数联合选参，避免被稳定长段 IoU 误导。
4. 重新收集一份阈值和模型均未查看的新目标集合后，再进行一次真正的冻结最终测试。
