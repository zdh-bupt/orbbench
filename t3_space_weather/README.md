# Chronos 2 空间天⽓预测



## 修复

(与 `SW-All.txt`  对比之后发现原始 `space_weather_daily.parquet` 的 `f107_obs` 与 `f107_adj` 列数据互换了)

原始匹配率为 79 / 7,504 = 1.05%

在不修改原始Parquet的情况下将原始 `space_weather_daily.parquet` 的 `f107_obs` 与 `f107_adj` 标签互换，在加载阶段使用以下映射：

```text
模型 f107_obs <- 原日表 f107_adj
```

互换之后匹配率达 7,491 / 7,504 = 99.83%

Kp 日均值继续由八个三小时 Kp 值计算，Ap 使用 `ap_avg`。Chronos 2 使用 `cross_learning=True` 来预测F10.7、Kp 和 Ap 。

## 实验配置

- 模型：`amazon/chronos-2`
- 设备：CPU
- 上下文长度：30、60、90 天
- 预测步长：3、7 天
- 每个回测配置：10 个滚动窗口
- 分位数：p10、p25、p50、p75、p90
- 正式预测：ctx90/pred7，与 GFZ definitive 真值比较

## 输入与输出

### 数据输入

历史输入数据：

`ai4ssa_datasets/数据集格式样例/space_weather/space_weather_daily.parquet`

筛选条件：

- 仅使用 `data_section = observed` 的日数据
- 清洗后共 24,739 天
- 日期范围：1957-10-01 至 2025-06-24
- 删除三个目标变量中存在缺失值的记录

输入变量：

| 模型变量       | 数据来源和处理                                      |
| -------------- | --------------------------------------------------- |
| `f107_obs`     | 使用原日表 `f107_adj`，该列经核验实际对应观测 F10.7 |
| `kp_daily_avg` | 对每日8个三小时Kp值取平均                           |
| `ap_avg`       | 使用日均Ap值                                        |

F10.7字段核验表明，在7,504个可比日期中有7,491个日期符合`f107_obs`和`f107_adj`标签互换关系，匹配率为99.83%。


### 模型输入

Chronos 2以日频长格式数据作为输入：

| 字段        | 含义             |
| ----------- | ---------------- |
| `item_id`   | 变量名称         |
| `timestamp` | 日期             |
| `target`    | 对应变量的历史值 |

实验分别使用30、60和90天历史上下文，并启用：

`cross_learning=True`

因此F10.7、Kp和Ap由模型联合预测。

### 模型输出

每个变量输出未来3天或7天的预测分布：

| 输出  | 含义                               |
| ----- | ---------------------------------- |
| `p10` | 第10百分位预测                     |
| `p25` | 第25百分位预测                     |
| `p50` | 中位数预测，也是本文使用的点预测值 |
| `p75` | 第75百分位预测                     |
| `p90` | 第90百分位预测                     |

`p25～p75`构成中央50%预测区间，
`p10～p90`构成中央80%预测区间。

### 回测输出

六组回测配置：

- ctx30/pred3
- ctx60/pred3
- ctx90/pred3
- ctx30/pred7
- ctx60/pred7
- ctx90/pred7

每组配置使用10个滚动窗口。

完整回测trace包含：

- 真实值 `true`
- 点预测值 `pred`
- 有符号误差 `error = pred - true`
- 绝对误差 `abs_error`
- 平方误差 `squared_error`
- 绝对百分比误差 `ape_percent`
- p10、p25、p50、p75、p90预测分位数

### 正式预测验证

正式预测使用 `ctx90/pred7`，预测日期为：

2025-06-25 至 2025-07-01

对应真值来自GFZ definitive数据，包括：

- F10.7 observed
- Kp日均值
- Ap日均值

最终输出包括完整trace、MAE、RMSE、Bias、预测区间覆盖率以及误差PDF/CDF图。

## 目录

- `forecasts`：六种配置的正式预测及 GFZ 验证 trace
- `backtests`：六种配置的完整滚动历史回测 trace
- `metrics`：正式预测与回测指标（数值形式的误差分析）
- `figures/combined`：CDF/PDF 汇总图
- `figures/individual`：12 张单独 CDF/PDF 图

## 完成状态与核验

- 正式预测验证：21 条记录（3 个变量 × 7 天）
- 回测 trace：900 条记录
- 回测配置：6 组，每组 10 个滚动窗口
- 独立 CDF/PDF 图：12 张
- 缺失值：0
- 重复 trace 主键：0

## 主要结果

正式预测（ctx90/pred7）与 GFZ definitive 真值比较：

| 变量 | MAE | RMSE | Bias | 80% 区间覆盖率 |
|---|---:|---:|---:|---:|
| F10.7 observed | 3.8571 sfu | 4.2508 sfu | -0.2177 sfu | 85.71% |
| Kp 日均值 | 0.7136 | 0.8329 | 0.3709 | 85.71% |
| Ap 日均值 | 6.4622 | 7.4075 | 0.5349 | 100.00% |

按聚合 MAE 比较，3 天和 7 天回测中三个变量均由 `ctx90` 取得最低误差，因此推荐配置仍为 `ctx90/pred7`。
