# 体素方法与逐星方法的 +1 h 密度对比图

## 比较范围

- 起报时刻：`2024-04-24T05:00:00Z`
- 目标时刻：`2024-04-24T06:00:00Z`
- 预测时效：`+1 h`
- 起报点闭集成员数：`4,092`
- 网格：`24 x 36 x 72`
- 网格分辨率：高度 `50 km`、纬度 `5 deg`、经度 `5 deg`

代表起报点结果：

| 方法 | Joint TV | CIC 密度质量重叠率 | Regional relative MAE（2x2x2） |
| --- | ---: | ---: | ---: |
| 体素残差网络候选模型 | 0.183922 | 81.607822% | 0.223702 |
| 逐星 Kepler + CIC | 0.172772 | 82.722844% | 0.201128 |

## 图表与数据

1. `01_density_six_panel.png/.pdf/.csv`
   - 真值密度、体素预测、逐星回投密度；
   - 两种方法的绝对误差；
   - 两方法优势区域。优势值为“逐星误差减体素误差”，正值表示体素候选模型在该经纬度列的误差更低。
2. `02_multiscale_overlap.png/.pdf/.csv`
   - 比较不同空间汇聚尺度下的 CIC 密度质量重叠率和相对计数误差；
   - 汇聚因子 `2` 对应正式 `2x2x2` Regional relative MAE 的空间尺度。
3. `03_altitude_profile_and_mass.png/.pdf/.csv`
   - 比较高度壳层密度；
   - 比较 `300 km` 以下、网格内和 `1500 km` 以上的质量，并核对总数守恒。
4. `04_paired_origin_scatter.png/.pdf/.csv`
   - 从锁定测试集的 `16,702` 个可用起报点中，按时间排序后执行确定性等秩抽样，得到 `96` 个配对起报点；
   - Joint TV 均值：体素候选模型 `0.183618`，逐星 Kepler + CIC `0.172212`；
   - Regional relative MAE 均值：体素候选模型 `0.222155`，逐星 Kepler + CIC `0.199687`；
   - 这 `96` 个起报点上，逐星路线在两项指标中均为 `96/96` 更低。
5. `comparison_report.json`
   - 保存输入文件哈希、方法状态、代表起报点指标、抽样规则、抽样统计及每个生成文件的 SHA-256。

第四张图是用于展示逐起报点稳定性的确定性抽样图，不替代完整锁定测试集的正式汇总。图中的 CIC 密度质量重叠也不是逐卫星精确落格率，因为 CIC 聚合后不再保留卫星身份。
